# Dan Rathke Product Portfolio Prototype

An interactive AI Product Management portfolio experience built with React, Tailwind CSS, Framer Motion, and sanitized local mock data.

This prototype is designed as a product experience, not a static resume site. It showcases how recurring customer pain points can become AI agents, product concepts, experimentation strategy, personalization adoption paths, and decision-support prototypes.

## Experience Focus

- Customer-informed product discovery
- AI agent concept design
- Experimentation program strategy
- Personalization adoption and maturity concepts
- Product thinking journey from signal to prototype
- Interactive portfolio storytelling for ELT and Product Management audiences

## Featured Artifacts

- ROI Agent
- Program Health Dashboard Agent
- Experimentation Gap Analysis Agent
- Personalization Maturity / Adoption Prototype
- CLEAR product thinking framework

## Data Safety

This repository uses front-end mock data only. Agent JSON examples are sanitized and illustrative. Do not commit confidential customer data, raw exports, original attached files, or private notes.
